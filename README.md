# Prompt Lab AI

Локальная AI-платформа для Android: Qwen GGUF, конструктор промтов, проекты, задачи, база знаний и последовательные AI-агенты.

## Версия 0.3.0 — текущая реализация

- Локальный Android Runtime через llama.cpp plugin: импорт GGUF, загрузка/выгрузка, потоковый чат.
- AI Studio: обычный диалог, последовательный режим агентов, остановка генерации, копирование переписки и новый чат.
- Быстрые стартовые подсказки для кода, анализа идеи, умного дома и улучшения промта.
- Конструктор промтов на локальном Qwen: превращает описание задачи в структурированный промт; сохраняет исходный и улучшенный варианты в библиотеку.
- Библиотека промтов на SQLite: создание, поиск, избранное и удаление.
- Избранное: просмотр, копирование и удаление отметки избранного.
- Проекты: локальное создание и удаление проектов, описание, список задач и статусы «Запланировано / В работе / Готово».
- База знаний: локальные заметки, поиск по заголовку/содержимому/тегам, закрепление, редактирование и удаление.
- История завершённых задач агентов: до 30 записей в локальном хранилище.
- Диагностика: доступность SQLite и app storage, состояние модели и сведения GPU/Vulkan.
- SQLite migration v1→v2 добавляет проекты, задачи и заметки без удаления старой таблицы промтов.

## Локальная модель

Откройте AI Studio → «Модели», выберите файл .gguf, импортируйте его и нажмите «Загрузить». Модель не включена в APK и не скачивается приложением автоматически. Начальная конфигурация Runtime — контекст 2048 токенов и четыре CPU-потока.

Для POCO X6 Pro 8 GB первичный кандидат — Qwen2.5 1.5B Instruct GGUF Q4_K_M; затем можно проверять Qwen2.5 3B Instruct GGUF Q4_K_M. Фактические скорость, память, Vulkan и устойчивость требуют теста на устройстве.

## Ограничения текущей версии

- Агенты — последовательные роли одной модели, не четыре независимые модели и не автономные исполнители.
- База знаний — локальные заметки с обычным текстовым поиском; embeddings и семантический retrieval ещё не подключены.
- Проекты и задачи хранятся локально; зависимости, автоматическое перепланирование и визуальный редактор workflow пока не реализованы.
- Диагностика проверяет доступность основных компонентов, но не выполняет стресс-тест температуры или длительной стабильности.
- Vision, OCR, загрузка моделей из каталога, backup/restore и фоновые очереди ещё не реализованы.
- Приложение не исполняет код и не управляет внешними устройствами самостоятельно.

## Стек

- Flutter / Dart — UI и прикладная логика.
- llama_flutter_android — локальная генерация через llama.cpp.
- SQLite — проекты, задачи, промты и заметки.
- SharedPreferences — небольшая локальная история задач агентов.
- GGUF — формат локальных моделей.

## Сборка

GitHub Actions собирает debug APK в ветке prompt-lab-foundation. Android platform files создаются в CI командой flutter create --platforms=android .

# Prompt Lab AI

Локальная AI-платформа для Android: Qwen GGUF, конструктор промтов, проекты, задачи, база знаний, память и последовательные AI-агенты.

## Основные возможности

- Локальный Android Runtime через llama.cpp plugin: импорт GGUF, загрузка/выгрузка и потоковый чат.
- AI Studio: локальный диалог, последовательный режим агентов, остановка генерации и история.
- Шесть последовательных ролей: Планировщик, Архитектор, Эксперт, Критик, Оптимизатор и Агент памяти. Все работают на одной загруженной модели, чтобы не держать несколько моделей в RAM.
- Агент памяти формирует кандидаты знаний для ручного подтверждения; автоматического скрытого сохранения нет.
- Конструктор промтов на Qwen с оценкой исходного запроса от 0 до 100 и подсказками по улучшению структуры.
- Библиотека промтов на SQLite, версии, поиск и избранное.
- Проекты, задачи, статусы и контрольные точки (checkpoints).
- Локальная база знаний: заметки, теги, поиск, закрепление, редактирование и удаление.
- Адаптивная память: подтверждённые факты, предпочтения и правила; релевантные записи и последние оценки ответов добавляются в контекст.
- История задач агентов сохраняется в локальной истории и SQLite.
- Центр интернет-исследований: Google, Яндекс и DuckDuckGo; анализ выбранных страниц выполняется локальной Qwen.
- Резервное копирование/восстановление базы в JSON.
- Импорт текстовых документов TXT и Markdown в базу знаний.
- Диагностика доступности SQLite, app storage и Runtime/GPU.

## Интернет-исследования

Три поисковых источника доступны без API-ключа: Google, Яндекс и DuckDuckGo. Можно выбрать один поисковик или искать сразу во всех трёх; результаты объединяются и дедуплицируются по URL. Текст страницы загружается и очищается от HTML, затем анализируется локальной GGUF-моделью Qwen. Вывод с URL источника можно сохранить в память.

Поисковики могут ограничивать автоматические запросы, менять HTML-разметку или показывать CAPTCHA. Парсинг выдачи не гарантирован постоянно; CAPTCHA не обходится. Интернет используется только для поиска и чтения страниц, AI-анализ остаётся локальным.

## Память и «самообучение»

Память хранит подтверждённые пользователем факты, предпочтения, правила и проектные сведения. Пользователь управляет записями вручную, может сохранять ответы из чата и оценивать их полезность. Релевантные знания подмешиваются в контекст. Это retrieval и адаптация контекста, а не fine-tuning: веса GGUF не изменяются.

## Резервные копии и документы

Из главного экрана или настроек доступны JSON экспорт/импорт пользовательской базы и импорт TXT/Markdown как заметок. Импорт резервной копии добавляет записи в существующую базу; перед восстановлением рекомендуется создать отдельную резервную копию. GGUF-файлы в backup не включаются.

## Локальная модель

Откройте AI Studio → «Модели», выберите файл .gguf, импортируйте его и нажмите «Загрузить». Модель не включена в APK и не скачивается приложением автоматически. Начальная конфигурация Runtime — контекст 2048 токенов и четыре CPU-потока.

Для POCO X6 Pro 8 GB можно начать с Qwen2.5 1.5B Instruct GGUF Q4_K_M; затем отдельно проверить Qwen2.5 3B Instruct GGUF Q4_K_M. Фактические скорость, память, Vulkan и устойчивость нужно измерить на устройстве.

## Что ещё не реализовано

- Семантический поиск через embeddings; текущий поиск памяти/заметок в основном лексический.
- Автоматическое извлечение, дедупликация и разрешение конфликтов памяти с подтверждением.
- Полноценный стенд prompt-тестирования с наборами кейсов, запуском Qwen и сравнением результатов.
- Сравнение версий промтов с подсветкой изменений.
- Зависимости задач, возобновление workflow и фоновая очередь Android.
- Полноценный импорт PDF/DOCX, разбиение документов на фрагменты и OCR/Vision.
- Адаптивная настройка Runtime и длительные стресс-тесты устройства.
- Автономное выполнение команд/кода и управление устройством не включены.

## Стек и сборка

- Flutter / Dart — UI и логика.
- llama_flutter_android — локальная генерация.
- SQLite — проекты, задачи, промты, заметки, память и история агентов.
- SharedPreferences — настройки и вспомогательная история.
- GGUF — формат локальных моделей.

GitHub Actions собирает debug APK в ветке `prompt-lab-foundation`. Основная ветка `main` не изменяется в рамках разработки этой функции.

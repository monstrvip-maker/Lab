# Prompt Lab AI

Локальная AI-платформа для Android: создание и анализ промтов, библиотека знаний, локальные модели Qwen, агенты и управление проектами.

## Текущий статус — 0.2.0

Добавлены:
- Flutter-приложение с базовой навигацией.
- Локальная SQLite-библиотека промтов.
- Android AI Runtime на базе llama.cpp через `llama_flutter_android`.
- Импорт GGUF-файла в приватное хранилище приложения.
- Определение возможностей GPU/Vulkan.
- Загрузка и выгрузка модели.
- Потоковый локальный чат с историей текущего диалога.

Это ещё не полная AI-платформа: агентный оркестратор, долговременная память, база знаний, автоматическое скачивание моделей и Vision Runtime будут реализованы отдельно.

## Локальная модель

В AI Studio откройте «Модели», выберите файл модели `.gguf`, импортируйте его и нажмите «Загрузить». Модель не включена в APK. Первый запуск проверяется на устройстве; для телефона с 8 ГБ RAM начальная конфигурация использует контекст 2048 токенов и четыре CPU-потока.

Рекомендуемые первые кандидаты для теста:
- Qwen2.5 1.5B Instruct GGUF Q4_K_M — более лёгкая проверка Runtime.
- Qwen2.5 3B Instruct GGUF Q4_K_M — основной кандидат после проверки памяти и скорости.

Проверьте лицензию модели и источник файла перед импортом.

## Стек
- Flutter / Dart — интерфейс и прикладная логика.
- Kotlin/JNI через llama.cpp plugin — локальный inference на Android.
- SQLite — структурированные данные.
- GGUF — формат локальных моделей.
- Никакие внешние AI API для генерации не требуются.

## Сборка

GitHub Actions собирает debug APK в ветке `prompt-lab-foundation`. Android platform files создаются в CI командой `flutter create --platforms=android .`.
